# Trendify - Shop What's Next 🛍️

## 🔥 Features

- Responsive Design (Mobile Friendly UI)
- Dynamic Navigation Menu
- Product Categories (Men, Women, Jewelry, Perfume, etc.)
- Product Showcase with Hover Effects
- Modal Popups for Newsletter Subscription
- Deal of the Day Section with Countdown Timer
- Notification Toast for Recent Orders
- Integrated with Ionicons for vector icons
- Clean, well-structured HTML & CSS files

| Technology | Purpose |
|-------------|----------|

| JavaScript | Interactivity and animations |
